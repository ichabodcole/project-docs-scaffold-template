# Fill the catalog in bulk and respell the index intro

Two rough edges filling `docs/index.md` on an adopting project:

1. No bulk fill. `pdocs new` writes a line for a new library page, but
   operator-mono had 138 existing pages (archived ones included), each needing a
   line whose hook equals its `description`. They were generated by a script.
2. After v3.0, the intro still lists the workbench as `backlog/`, `briefs/`,
   `investigations/`, `projects/`, `reports/`, `fragments/`, `cycles/`. The file
   is the project's, so no migration refreshes it, but that sentence is scaffold
   text describing retired folders.

Reported in
[#196](https://github.com/ichabodcole/project-docs-scaffold-template/issues/196).

## Definition of done

- [ ] A way to add missing library pages to the catalog (archived pages in a
      sub-list) and resync stale hooks, e.g. `pdocs catalog [--write]`.
- [ ] v3.0 respells the intro sentence when it still matches the scaffold's
      text.
