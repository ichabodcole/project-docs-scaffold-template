**Method.** A runner (`watch-guards-fail.ts`, scratchpad) took the intact file,
and for each guard in turn: replaced that one guard's condition with `false` (or
removed its `fail(` call) **in place**, ran the covering test with
`bun test <file> -t <name>`, recorded the red count and the names of the tests
that went red; restored the intact file byte-for-byte; ran the same test again
and recorded green. The runner refuses a guard whose text it cannot find, so a
renamed guard cannot be silently skipped — which is how I1 was caught after the
review changed its text (`if (!cfgOnDisk)`), and re-run alone. 48 guards, 0
problems; `grep -c 'if (false)'` on both restored files is 0. Line numbers are
of the files as run.

### Not guards, but asserted

- Every stop names the tree's state: `Nothing was written.` on a preflight stop,
  `The tree may be partly migrated. Re-running is safe` after a writing phase
  (`a stop after a writing phase says the tree may be partly migrated; a preflight stop says nothing was written`).
- An inert undeclared folder (empty; `.obsidian/workspace.json`; all its
  markdown under a `lint.exclude` glob or a skipped name) is a `·` note and not
  a stop; the same dot folder with a `.md` in it is (two tests, plus the
  `undeclaredFolders` unit test with all four inert shapes).
- `bumpVersion` reports a README it could not set with `·`, and I9 fails the run
  (unchanged witness, review item 6).
